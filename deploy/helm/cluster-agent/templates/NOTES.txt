KubeX cluster agent installed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

Verify the pod is running:
  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

Tail its logs (bootstrap runs immediately — discovery/heartbeat should
appear within a few seconds):
  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }} -f

Confirm the platform is receiving heartbeats: open the KubeX Settings page
and check this cluster's "Last heartbeat" timestamp, or query the ingest
API directly:
  curl -s -H "Authorization: Bearer <your session token>" \
    {{ .Values.endpoint }}/api/clusters
